# 로그인 · 접근 통제

운영 UI 와 API 는 **로그인한 사람만** 씁니다 (기본 켜짐). 계정은 운영 저장소 `migration_user`, 권한(역할)은 `migration_role` 에 있습니다. 사용자는 권한 하나에 속하고, 권한이 **볼 수 있는 메뉴**와 메뉴마다 **조회만 / 실행까지**, **유휴 잠금 시간**을 정합니다. 권한과 사용자는 **총관리자**(한 사람)가 관리합니다.

## 처음 띄웠을 때

1. 앱을 처음 기동하면 계정 테이블이 비어 있습니다. 서버는 비밀번호를 **만들지도, 로그에 남기지도 않습니다**. 운영 UI 에 처음 접속하면 로그인 화면 대신 **초기 설정** 화면(`/setup`)이 떠서 거기서 관리자 `admin` 의 비밀번호(8자 이상)를 정합니다. 그 전까지 다른 화면은 모두 `/setup` 으로 가고, API 는 503 `SETUP_REQUIRED` 입니다 (헬스체크 `/actuator/health/**` 는 열림).
2. 정하면 로그인 화면으로 가고, 그 비밀번호로 로그인합니다. 고정 기본 비밀번호(`admin/admin` 같은 것)도, 환경 변수 초기값도 없습니다.
3. 초기 설정 화면은 **먼저 접속하는 사람**이 봅니다. 기동하자마자 운영자가 정하고, 앱은 신뢰할 수 있는 내부망에만 두세요 (SECURITY.md). 계정이 생기면 `/setup` 은 로그인 화면으로만 보냅니다.

## 권한 · 사용자 관리 (총관리자)

메뉴 **점검·관리 › 사용자 · 권한** (`/ui/users` · `/ui/roles`). 총관리자에게만 보입니다.

### 권한

처음 기동하면 기본 권한 셋이 생깁니다.

| 권한 | 메뉴 | 고치기 · 지우기 |
|---|---|---|
| **관리자** | 모든 메뉴 실행 + 권한 · 사용자 관리 + 이관 설계 · Swagger · 서버 진단 · 채번 API. **총관리자 한 사람만** 속한다 | 유휴 잠금 시간만 바꿀 수 있다. 지울 수 없다 |
| **실행자** | 이관 진행 · 테이블 이관 실행 · 시나리오 · 엑셀 · 실행 현황 · 이력 · 실행 전 점검 = 실행. 대시보드 · 테이블 현황 · 알림 · 시스템 · 로그 · DDL 도구 = 조회 | 된다 |
| **조회자** | 대시보드 · 테이블 현황 · 실행 현황 · 이력 · 알림 = 조회 | 된다 |

- **권한 추가**: 이름 · 설명 · 유휴 잠금(분, 0 = 끔) · 메뉴 표에서 메뉴마다 **없음 / 조회 / 실행**. "기본 권한에서 복사" 로 실행자 · 조회자 값에서 시작할 수 있습니다.
- **조회** = 그 메뉴 화면 보기 · 목록 · 상세 · 내려받기(보고서 파일 만들기 포함). **실행** = 조회 + 실행 · 저장 · 중지 · 삭제. 실행 단계가 없는 메뉴(대시보드 · 알림 · 로그 등)는 조회까지만 있습니다.
- 이관 설계 · 권한 · 사용자 관리 · Swagger · 서버 진단 · actuator · 채번 API 는 **관리자 전용**이라 다른 권한에 줄 수 없습니다.
- **권한 삭제는 그 권한의 사용자도 함께 지웁니다.** 확인 창이 지워질 사용자 목록을 보여 주고, 권한 이름을 다시 입력해야 지워집니다. 사용자를 남기려면 먼저 다른 권한으로 옮기세요.

### 사용자

- **추가**: 아이디(영문 · 숫자 · `. _ -` 2~50자) · 이름 · 권한 · **초기 비밀번호(관리자가 정함, 8자 이상)**. 정한 비밀번호는 사용자에게 따로 전하세요. 사용자는 첫 로그인 때 비밀번호를 바꿔야 다른 화면을 쓸 수 있습니다.
- **고치기**: 이름 · 권한. **비밀번호 초기화**: 관리자가 새 값을 정하고, 다음 로그인 때 다시 변경 강제. **잠금 풀기**: 5회 실패 잠금 해제.
- **사용 중지 · 다시 사용 · 삭제**. 사용자를 지워도 실행 기록의 실행자 이름은 남습니다. 잠깐 막기만 하려면 사용 중지를 쓰세요.
- **총관리자**는 다른 권한으로 옮기거나, 사용 중지 · 삭제할 수 없습니다. 관리자 권한에 다른 사용자를 넣을 수도 없습니다. 총관리자 비밀번호는 **내 계정**에서 바꿉니다.

### 언제 적용되나

권한 · 사용자를 바꾸면 그 사용자의 **다음 요청부터** 적용됩니다 (다시 로그인할 필요 없음). 사용 중지 · 삭제된 사용자는 다음 요청에서 로그아웃되어 로그인 화면(`/login?disabled`)으로, API 는 401 `ACCOUNT_DISABLED`. 열려 있는 화면의 사이드바는 새로고침해야 바뀝니다.

### 권한이 없을 때

- 사이드바에는 볼 수 있는 메뉴만 나옵니다. 주소를 직접 쳐도 **권한 없음** 화면(403)이 뜹니다.
- 조회만인 메뉴의 화면에서는 실행 · 변경 버튼이 보이지 않고, 화면 위에 "조회 권한입니다" 한 줄이 뜹니다.
- API 를 직접 부르면 403 `FORBIDDEN`. 화면에서 숨기는 것은 편의이고, 막는 것은 서버입니다.
- 한 API 를 여러 메뉴가 같이 쓰면(예: 실행 목록 `/api/report/jobs` 는 테이블 현황 · 이력 · 실행이 같이 씀) 그중 한 메뉴 권한만 있어도 그 API 는 열립니다. 메뉴 단위 통제이고, 테이블 · 업무별 데이터 권한은 없습니다.

## 비밀번호를 잊었을 때

- **일반 사용자**: 총관리자가 사용자 관리에서 비밀번호를 초기화합니다.
- **총관리자**: 서버 운영자가 환경 변수 `GEORU_ADMIN_RESET_PASSWORD=true` 로 앱을 **한 번** 재기동합니다. **총관리자 계정만** 지워져 다음 접속이 다시 **초기 설정** 화면이 되고, 거기서 새 비밀번호를 정합니다. 다른 사용자 · 권한은 그대로 남습니다 (총관리자를 정하기 전까지는 다른 사용자도 쓸 수 없습니다). 재기동이 끝나면 **환경 변수를 지우세요** — 켠 채로 두면 재기동마다 총관리자 계정이 지워집니다 (로그가 경고합니다).

운영 저장소에서 `migration_user` 의 관리자 행(`role_id = 'ADMIN'`)을 지우고 재기동해도 같습니다.

## 잠금

| 종류 | 동작 | 조절 |
|---|---|---|
| 로그인 실패 잠금 | 5회 연속 실패 → 15분 동안 로그인 거부. 로그인 화면에 남은 시간 | 고정. 일반 사용자는 관리자가 사용자 관리에서 **잠금 풀기**, 총관리자는 리셋 재기동 |
| 유휴 잠금 | 마우스 · 키보드 입력이 N분 없으면 **자동 로그아웃** → 로그인 화면. 실행 중인 이관은 서버에서 계속 돕니다 | **권한마다** 총관리자가 권한 관리에서 분 단위(기본 30, `0` 이면 끔). 그 권한의 사용자는 모두 같은 값을 따릅니다. **다음 화면 로드부터** 적용 (열려 있던 탭은 새로고침). |

유휴 잠금은 화면(브라우저)이 검사합니다. 폴링 · 자동 새로고침은 입력으로 세지 않습니다. 서버 세션은 별도로 Boot 기본 30분 뒤 끝납니다.

## 스크립트 · 자동화

같은 계정으로 **HTTP Basic** 을 씁니다. 세션 로그인과 달리 CSRF 토큰이 필요 없습니다. 권한 판단도 화면과 같습니다 — 게이트 · 자동화에는 총관리자 계정이나 실행 권한이 있는 계정을 쓰세요.

```
curl -u admin:비밀번호 -X POST http://localhost:8081/api/scenarios/demo-full/run -H 'Content-Type: application/json' -d '{"testMode":"NORMAL"}'
```

비밀번호를 바꾸기 전(초기 · 리셋 직후)에는 Basic 으로도 변경 API 만 됩니다:

```
curl -u admin:초기값 -X POST http://localhost:8081/api/account/password -H 'Content-Type: application/json' -d '{"currentPassword":"초기값","newPassword":"새값"}'
```

데모 도커는 `./run-scripts/run-docker.sh admin-password` 가 이 절차(로그에서 초기값 읽기 → 무작위 새 값으로 변경 → `docker/volumes/.admin-password` 에 보관)를 한 번에 합니다. 그 파일은 git 에 올라가지 않습니다.

## 실행자

실행 기록 · 생성 기록의 **실행자**는 로그인한 사람의 표시 이름입니다. 서버가 `X-Executed-By` 헤더를 로그인 이름으로 바꾸므로 클라이언트가 다른 이름을 보낼 수 없습니다. 로그인이 꺼져 있을 때만 화면 상단의 "실행자" 칸이 쓰입니다.

## 끄기 (테스트 · 로컬 개발)

`georu.security.enabled=false` (환경 변수 `GEORU_SECURITY_ENABLED=false`). 모든 경로가 열리고 로그인 화면이 없습니다 (0.6 과 같음). 기동 로그에 경고가 남습니다. 운영에서는 끄지 마세요.

## 경로별 통제

| 경로 | 켜졌을 때 |
|---|---|
| `/login` · `/logout` · `/ui-assets/**` · `/actuator/health/**` · 이 안내서(`/api/ui/guides/login`) | 누구나 (헬스체크 · 로그인 화면용) |
| `/api/**` · 그 밖의 `/actuator/**` · `/admin/**`(서버 진단) | 로그인 세션 또는 HTTP Basic. 아니면 401 JSON `UNAUTHORIZED` |
| `/ui/**` · Swagger | 로그인. 아니면 로그인 화면으로 |

로그인한 뒤에는 권한의 메뉴 단계로 판단합니다 (위 "권한이 없을 때"). 표에 없는 API · Swagger · 서버 진단 · `/actuator/**`(health 제외)는 관리자만입니다.

서버 진단(Spring Boot Admin)은 앱이 자기 자신을 HTTP 로 부르므로, 기동 때 무작위 비밀번호의 내부 계정 `georu-internal` 을 메모리에만 만들어 씁니다. 화면 · 로그 · 저장소에 남지 않습니다.

## 문제 해결

| 증상 | 원인 · 조치 |
|---|---|
| 기동 실패 "migration_user 테이블이 없습니다" · "migration_role 테이블이 없습니다" · "V13 전입니다" | `georu.operation.schema-init=never` 환경. DBA 가 `operation/schema/old/V11__user-{h2,mysql}.sql` · `V13__roles-{h2,mysql}.sql` 을 순서대로 실행 (새 저장소면 전체 DDL `operation/schema/georu-operation-{h2,mysql}.sql`). 기본 권한 행은 앱이 기동 때 넣습니다 |
| 화면이 "권한 없음" · API 가 403 `FORBIDDEN` | 내 권한에 그 메뉴가 없거나 조회만입니다. 총관리자에게 권한을 요청. 내 권한은 **내 계정** 에 보입니다 |
| 로그인 화면에 "사용 중지되었거나 지워진 계정" · API 401 `ACCOUNT_DISABLED` | 총관리자가 사용 중지 · 삭제했거나, 권한이 지워지면서 함께 지워졌습니다 |
| 기동 로그 "관리자 권한 사용자가 N명" | 운영 저장소를 직접 고쳐 관리자 권한 행이 여럿. 먼저 만든 하나가 총관리자이고, 나머지는 사용자 관리에서 다른 권한으로 옮기세요 |
| 화면 저장 · 실행이 403 | CSRF 토큰 없음. 화면은 `ui.js` 가 자동으로 붙입니다. 직접 만든 호출이면 쿠키 `XSRF-TOKEN` 값을 헤더 `X-XSRF-TOKEN` 으로, 또는 HTTP Basic 으로 |
| 운영 저장소에서 총관리자 행을 직접 지웠는데 로그인 화면이 뜸 | "총관리자 있음" 을 **30초** 동안 기억합니다. 30초 안에 초기 설정 화면(`/setup`)으로 바뀝니다. 시간은 `georu.security.setup-cache` (기본 `30s`, 예: `10s`) 로 바꿉니다. 화면 · 리셋 스위치로 지우면 바로 바뀝니다 |
| API 가 503 `SETUP_REQUIRED` | 관리자 계정이 아직 없음 (처음 · 리셋 직후). 브라우저로 `/setup` 에서 비밀번호를 정한다. 데모 도커는 `run-docker.sh admin-password` |
| API 가 403 `PASSWORD_CHANGE_REQUIRED` | 비밀번호 변경이 필요한 상태. 변경 API 로 먼저 바꾼다 |
| 도커 헬스체크 unhealthy | `/actuator/health/live` 는 열려 있습니다. 다른 경로를 헬스체크로 쓰면 401 |
| 서버 진단 화면에 인스턴스가 안 보임 | `georu.admin-console.enabled=true` 인지, 기동 로그에 내부 계정 오류가 없는지 |
| `libs/` 방식 업체 프로젝트가 컴파일 실패 | `spring-boot-starter-security` 가 필요합니다. 의존성 목록에 추가 |
