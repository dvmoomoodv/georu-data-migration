    점검 기준

    • 차단: NOT NULL 위반, 길이 초과, 타입 변환 불가, 숫자·날짜 범위 초과, INSERT 에 빠진 NOT NULL 컬럼, 타겟에 없는 컬럼, 변환 오류, 원천 미지정
    • 경고: 소수 자릿수 반올림, 샘플 내 PK 중복, 타겟 기존 데이터, 조회 불가(권한 또는 테이블 없음), 판단 불가(DB 규칙 없음), INSERT 해석 불가
    • 샘플은 기존 페이징 쿼리로 전체를 구간으로 나눠 구간마다 읽습니다 (모든 DB 공통). 구간마다 시간 제한이 있어 넘기면 그 구간은 건너뜁니다.
    • DB 규칙이 없는 타겟은 길이·날짜 범위를 "판단 불가"로 표시합니다 → 수작업 확인 가이드
