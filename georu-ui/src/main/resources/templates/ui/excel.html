2. 실행 파일 목록에서 파일을 선택하세요

자동 점검 해당 없음 엑셀 이관은 자동 실행 전 점검 대신 업로드 검증(타겟 컬럼 길이 · NOT NULL · 타입)을 씁니다. 이관 상태 · 기존 데이터 확인은 테이블 실행과 같습니다.
테넌트 (기본 DEFAULT)
그룹 · 계열사 · 사업부 · 부서 · 팀 - 소스에 단위 컬럼이 없으면 회사명으로 모두 채웁니다
실행 결과는 실행 현황·이력 화면에서 추적합니다 (migrationId).

선택 파일

파일 목록에서 행을 누르면 여기에 검증 결과 · 건너뛴 행이 나옵니다.
타겟 컬럼 ↔ DTO 대응, 필수 · 감사 · 채번 컬럼 (1. 템플릿 · 업로드의 플러그인 · 테이블 기준)
파일 목록에서 파일을 고르고 미리보기 를 누르면 앞 20행이 나옵니다.
상한을 넘거나 넘을 것 같으면 한 테이블을 행 범위로 나눠 파일 여러 개로 올립니다
  1. 데이터 행 수와 열 수를 넣고 "계산" → 파일당 행 수와 파일별 범위가 나옵니다 (예: 1~1,000행 파일 1개, 1,001~2,000행 파일 1개).
  2. 원본을 범위대로 나눕니다. 파일마다 1행 헤더를 그대로 둡니다. 이름은 제안 이름처럼 순번·범위를 붙이면 순서를 잃지 않습니다.
  3. 같은 테이블로 하나씩 업로드 → 검증 통과를 확인합니다. 파일 사이 PK 중복은 검증하지 않으니 범위가 겹치지 않게 나눕니다.
  4. 첫 파일부터 차례로 실행합니다. 두 번째 파일부터는 앞 파일이 넣은 데이터 때문에 NORMAL 이 "기존 데이터" 로 멈추므로 "기존 데이터가 있어도 적재"를 켭니다.
  5. 행이 많으면 xlsx 대신 CSV(UTF-8) 로 저장하면 셀 수 제한이 없습니다 (파일 크기 상한만 적용).
