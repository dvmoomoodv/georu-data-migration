처음 보는 분을 위한 한 장

1. 이 프로그램은

소스 DB 의 테이블을 읽어 변환한 뒤 타겟 DB 에 적재하는 데이터 이관 프로그램입니다. 매핑이 정해진 상태에서 쿼리와 초급 수준 자바만으로 이관이 안정적으로 끝나도록, 실행·점검·채번·기록·알림을 제품이 맡습니다.

Reader 소스 SELECT 를 페이지로 읽고 → Processor 타겟 모양으로 바꾸고 → Writer 묶어서 INSERT 합니다.
테이블마다 이 셋을 만들고, 업무 단위(플러그인)로 묶습니다. 개발자가 쓰는 것은 Source SQL · Processor 몇 줄 · Target SQL 입니다.

제품 원칙 3개

  1. 타겟 데이터를 지우지 않습니다. 기존 데이터가 있으면 경고 후 멈추고, 정리는 사람이 안내서대로 합니다.
  2. 한 번에 하나만 실행합니다. 실행 중이면 새 요청은 거절(409)되고, 실행 목록은 순서대로 기다립니다.
  3. 실행·중단·정리는 사람이 화면에서 합니다. 제품은 안내하고 기록합니다.
구조 설명용어 사전

2. 처음 10분

  1. 시스템 화면에서 DB 3개(소스·타겟·운영저장소)가 UP 이고 플러그인이 보이는지 확인합니다. 열기
  2. 오른쪽 위 실행자 칸에 이름을 넣습니다. 이력에 남습니다.
  3. 테이블 이관 실행에서 플러그인·테이블을 고르고 테넌트 5칸을 업체 값으로 바꿉니다. 모드는 기본 WRITER_TEST(적재 100건)로 지금 실행. 오른쪽 진행 현황에서 결과를 봅니다. 열기
  4. 결과가 맞으면 샘플 100건을 수작업 정리 안내서대로 정리하고, 모드를 NORMAL 로 바꿔 전량 이관합니다. 여러 테이블은 + 목록에 순서대로 쌓아 실행합니다.
  5. 이력에서 건수·소요·보고서를 확인합니다. 같은 테이블을 다시 실행해 보면 "기존 데이터 차단"이 어떻게 동작하는지 볼 수 있습니다. 열기
