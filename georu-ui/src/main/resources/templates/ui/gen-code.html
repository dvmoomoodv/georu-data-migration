코드 생성

TOBE 컬럼 정의를 올리면 업체 적용 전 필수 파일(기본 셋트 · 업무 Strategy · 테이블별 Reader · Processor · Writer · DTO · XML)을 zip 으로 만든다 · 올린 파일은 저장하지 않는다

1. 파일 올리기

TOBE 컬럼 정의서(한 행에 컬럼 하나, xlsx · xls · CSV)를 올린다 · 열 설명은 ? 도움말
TOBE 컬럼 정의 를 끌어다 놓거나 클릭 (CSV · xlsx · xls 첫 시트)
ASIS 테이블 정의 (테이블명 · 컬럼명 · 타입, 있으면 PK)
업체 규칙 파일 선택 · xlsx (기본값 · 사전 · 감사 컬럼 · 명명 규칙)
올리면 2. 설정이 파일 값으로 채워진다 · 서버에 남지 않는다

2. 설정

-
파일을 올리면 업무구분 목록이 나온다

3. 검사 결과

zip 안의 APPLY.md 와 같은 내용
  1. TOBE 컬럼 정의를 올리고, 업체 단어와 업무구분별 패키지 이름을 넣는다.
  2. 검사로 오류 · 경고 · 테이블별 결과를 본다. 원천 테이블이 없는 테이블은 골격(WHERE 1 = 0)으로 만들어지고 실행 전 확인에서 막힌다.
  3. zip 내려받기 → 저장소 루트에서 unzip -n <zip> -d . (이미 있는 파일은 덮지 않는다).
  4. 검사가 통과하면 여기에 적용 순서 · 설정 · 해야 할 일이 나온다.
